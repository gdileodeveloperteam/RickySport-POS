\# Frontend Bootstrap Designer



\## Purpose

Design and implement clean, modern, professional frontends using \*\*Bootstrap 5\*\* and vanilla HTML/CSS/JS.

Focus on readability, spacing, hierarchy, and business-grade UI.



\## Auto-activation keywords

\- bootstrap

\- frontend

\- ui

\- layout

\- html

\- css

\- dashboard

\- form

\- modal

\- table

\- navbar

\- card



\## Design Principles (MANDATORY)

\- Use \*\*Bootstrap 5 utilities first\*\* (spacing, grid, flex)

\- Consistent spacing (`mb-3`, `p-3`, `gap-\*`)

\- Clear visual hierarchy (headers, sections, cards)

\- Neutral, professional color palette

\- Mobile-first responsive design

\- Accessibility-friendly markup (labels, aria when needed)



\## Allowed

\- Bootstrap 5 (CDN or local)

\- Vanilla JS

\- Custom CSS (scoped and minimal)

\- Icons: Bootstrap Icons or FontAwesome (CDN)



\## Forbidden

\- React / Vue / Angular

\- Tailwind

\- Inline styles unless strictly necessary

\- Over-styling or “marketing UI”

\- Breaking existing DOM structure without approval



\## Responsibilities

\- Improve UI clarity without changing business logic

\- Refactor messy markup into semantic HTML

\- Use cards, tables, modals, and forms appropriately

\- Align UI with enterprise / admin-panel standards



\## Workflow

1\. Identify the UI component(s) involved

2\. Propose a minimal visual improvement plan

3\. Apply Bootstrap layout and utilities

4\. Add minimal scoped CSS only if required

5\. Ensure responsive behavior

6\. Preserve existing IDs, JS hooks, and data attributes



\## Output Expectations

\- Provide full HTML snippets when modifying structure

\- Provide diff-style changes for small tweaks

\- Explain design decisions briefly (1–3 bullets)
